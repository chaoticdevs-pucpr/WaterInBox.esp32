# WaterInBox.esp32
Repositório dedicado aos arquivos do projeto WaterInBox, desenvolvido e finalizado na disciplina de Performance em Sistemas Ciberfísicos da Pontifícia Universidade Católica do Paraná (PUCPR).

## Sobre o Projeto
O WaterInBox é um sistema de monitoramento para caixas d'água criado para evitar o desperdício causado por vazamentos silenciosos. 

O dispositivo, construído com um ESP32, mede constantemente a entrada e a saída de água. Além disso, o sistema analisa se a água está escoando de forma constante. Caso esse fluxo ultrapasse um limite configurado pelo próprio usuário, o sistema identifica isso como um vazamento e bloqueia a passagem da água automaticamente. 

Os dados coletados pelos sensores são integrados a uma interface web. Isso, permite o monitoramento em tempo real através de gráficos e também oferece a opção de realizar o bloqueio do fluxo de forma manual.
